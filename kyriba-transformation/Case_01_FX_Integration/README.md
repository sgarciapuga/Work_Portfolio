## Case summary

The case follows the move from manual FX trade re-entry to connected execution:

1. The client submits an FX request in Kyriba.
2. FX details are sent to the trading platform with the request pre-populated.
3. The trader executes the best available deal.
4. Execution details return to Kyriba and update the trade automatically.
5. The client receives end-of-day activity information or a confirmation download.

The source presentation reports approximately 15 to 5 minutes execution time, 99% fewer manual input errors and approximately $4,000 per year in avoided rework and market-exposure risk. Those are source-reported estimates and are kept qualified in the report.
